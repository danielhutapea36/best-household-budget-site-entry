Hearth is a household budget site that runs entirely in the browser: a monthly dashboard with income, spending and savings at a glance, a spending-by-category chart, per-category budgets you can set and watch, savings goals with progress, and insights that read the month's figures back to you. Add, filter and delete transactions; everything is stored in localStorage, so it is still there next time you open it. The demo household (the Alvarez family, November 2026) ships with the site — replace its figures with your own and it keeps working.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser or on a phone. No build step, no network: `app/` is plain static files.
